# O# Online Feedback System

A web-based Online Feedback System developed to collect and manage student feedback using HTML, CSS, PHP, and MySQL.

## 📌 Project Overview

The Online Feedback System provides a simple interface for students to submit feedback about their teachers and subjects. Feedback is stored in a MySQL database and can be managed through the application's available pages.

## ✨ Features

- Student feedback submission form
- Teacher login interface
- Teacher dashboard
- Teacher and subject selection
- Semester selection
- Rating and comment submission
- MySQL database integration
- Thank-you page after feedback submission

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS
- **Backend:** PHP
- **Database:** MySQL
- **Local Development Environment:** XAMPP
- **Database Management:** phpMyAdmin

## ⚙️ How to Run the Project Locally

1. Install and open XAMPP.
2. Start Apache and MySQL from the XAMPP Control Panel.
3. Copy the project folder into the `htdocs` directory.
4. Open phpMyAdmin at `http://localhost/phpmyadmin`.
5. Create a database named `feedback_system`, if it does not already exist.
6. Import the `feedback_system.sql` file into the database.
7. Configure the database connection in `db.php` using your local MySQL settings.
8. Open the project in your browser using:

   `http://localhost/Online-feedback-system/frontpage.php`

   Adjust the folder name in the URL if your local project folder has a different name.
